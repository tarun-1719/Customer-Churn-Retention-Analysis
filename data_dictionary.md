# Data Dictionary

## Project: Customer Churn & Retention Analysis

**Dataset:** IBM Telco Customer Churn  
**Database:** customer_churn_db  
**Table:** customer_churn  
**Tool:** MySQL 8.0

## Column Descriptions

| Column Name | Description |
|---|---|
| customerID | Unique identifier for each customer |
| gender | Customer gender |
| SeniorCitizen | Indicates whether the customer is a senior citizen |
| Partner | Whether the customer has a partner |
| Dependents | Whether the customer has dependents |
| tenure | Number of months the customer has stayed |
| PhoneService | Phone service subscription status |
| MultipleLines | Multiple phone lines subscription status |
| InternetService | Internet service type |
| OnlineSecurity | Online security subscription status |
| OnlineBackup | Online backup subscription status |
| DeviceProtection | Device protection subscription status |
| TechSupport | Technical support subscription status |
| StreamingTV | Streaming TV subscription status |
| StreamingMovies | Streaming movies subscription status |
| Contract | Customer contract type |
| PaperlessBilling | Paperless billing status |
| PaymentMethod | Customer payment method |
| MonthlyCharges | Monthly charges for the customer |
| TotalCharges | Total recorded charges for the customer |
| Churn | Whether the customer left the service |
| ChurnFlag | Numeric churn indicator (1/0) |
| TenureGroup | Categorized customer tenure |
| MonthlyChargeGroup | Categorized monthly charges |
| TotalChargeGroup | Categorized total charges |
| HighRiskCustomer | Derived customer risk classification |
| CustomerValue | Derived customer value category |

## Purpose

This data dictionary explains the columns used in the Customer Churn & Retention Analysis project. It supports understanding of the dataset and the SQL analysis.
